# 다른 앱에서 가져온 패턴

클로바노트와 네이버 캘린더가 화면을 어떻게 짜고 어떻게 움직이는지 살펴보고, 우리 앱에 맞는 것만 골라 디자인 시스템에 넣었어요.
구조와 동작 방식만 참고했어요. 그림, 글꼴, 색 값, 코드는 가져오지 않았어요.

- 살펴본 날: 2026-11-17
- 살펴본 방법: 공개된 앱 설명, 공식 도움말, Android 앱의 화면 구성 분석, 사용자가 찍은 화면
- 원본 분석 보고서는 `docs/benchmark/raw/`에 두고 레포에는 올리지 않아요 (`.gitignore`).

## 뼈대는 둘을 섞어요

| | 클로바노트 | 네이버 캘린더 | 우리 앱 |
|---|---|---|---|
| 하단 탭 | 4개 (홈, 폴더, 캘린더, 설정) | 없음 | 4개 (홈, 카드, 피드, 검색) |
| 왼쪽 메뉴 | 없음 | 있음 (기능 바로가기, 캘린더별 켜고 끄기) | 있음 (빠른 실행, 세션, 카드, 캘린더 켜고 끄기) |
| 만들기 버튼 | 홈에 하나, 누르면 4개가 펼쳐짐 | 화면에 하나, 누르면 작성 메뉴 | 홈에 빠른 도구 하나, 누르면 녹음과 AI에게 묻기 |

자주 가는 곳은 하단 탭에, 가끔 가는 곳과 목록은 왼쪽 메뉴에 둬요. 만들기는 두 앱 모두 "버튼 하나에서 펼치기"라서 그대로 따라요.

## 가져온 것

| 우리 화면 | 가져온 패턴 | 출처 | 컴포넌트 | 화면 |
|---|---|---|---|---|
| 홈 | 떠 있는 버튼 하나에서 도구 펼치기 | 둘 다 | `SpeedDial` | 홈 |
| 홈 | 오늘 일정과 할 일을 한 목록에 이어 보여 주고, 할 일은 바로 체크 | 네이버 캘린더 | `TaskCheckRow` | 홈 |
| 녹음 | 전체 화면 대신 시트. 끌어내리면 작은 막대로 줄고 녹음은 계속 | 클로바노트 | `RecordPanel`, `RecordMiniBar` | 녹음 시트 |
| 녹음 | 녹음 중 북마크, 시각이 붙는 메모 | 클로바노트 | `RecordPanel` | 녹음 시트 |
| 녹음 노트 | 탭 3개: 받아쓴 글, 요약, 메모. 검색하면 탭에 개수 | 클로바노트 | `CountTabs` | 녹음 노트 |
| 녹음 노트 | 단어를 누르면 그 자리부터 재생 | 클로바노트 | `TranscriptBlock`, `PlayerBar` | 녹음 노트: 받아쓴 글 |
| 녹음 노트 | 구간을 길게 누르면 동작을 시트 하나에 모음 | 클로바노트 | `ActionRow` | 구간 길게 누르기 |
| 요약 | 구역마다 접는 카드, 고친 구역 표시, 틀릴 수 있다는 안내 | 클로바노트 | `SummarySection`, `AiNotice` | 녹음 노트: 요약 |
| 요약 | 어떤 양식으로 정리했는지 고르기 (우리는 세션 양식과 같은 것) | 클로바노트 | `SummaryHeader` | 녹음 노트: 요약 |
| 캘린더 | 위는 달력, 아래는 그날 목록. 달력만, 반반, 하루만 3단계 | 네이버 캘린더 | `MonthGrid`, `DualHandle` | 캘린더: 달력과 목록 |
| 캘린더 | 날짜를 길게 누르면 그 자리에 빠른 메뉴 | 네이버 캘린더 | `QuickActionMenu` | 날짜 길게 누르기 |
| 캘린더 | 그날 목록에 일정, 할 일, 끝낸 일, 기록을 이어서 | 네이버 캘린더 | `DaySectionTitle` | 캘린더: 달력과 목록 |
| 왼쪽 메뉴 | 캘린더별로 켜고 끄기 | 네이버 캘린더 | `LnbToggle` | LNB 드로어 |
| 설정 | 맨 위에 남은 사용량 카드, 기능별 묶음 | 둘 다 | (화면에서 조립) | 설정 (묶음 정리) |

## 다르게 한 것

| 두 앱은 | 우리는 | 이유 |
|---|---|---|
| 요약의 "다음 할 일"이 글 목록 (클로바노트) | 확인 기다리는 카드로 보여 줘요 (`NextActionRow`) | 확인한 것만 저장하고, 캘린더 시간 잡기로 이어져요. 우리 앱의 핵심이에요 |
| 지울 때 확인 창 (네이버 캘린더) | 바로 지우고 되돌리기 막대를 보여 줘요 (`Toast`) | 묻는 창이 적을수록 빨라요 |
| 일정 완료는 상세 화면의 스위치 (네이버 캘린더) | 할 일은 목록에서 바로, 4가지 선택은 줄을 눌러서 | 저녁 수행 확인이 한 번에 끝나야 해요 |
| 스티커, 일러스트 테마, 날씨 (네이버 캘린더) | 넣지 않아요 | 우리 앱의 범위 밖이에요 |
| 화자 구분, 대화 비율 (클로바노트) | 아직 넣지 않아요 | 받아쓰기가 화자를 나누지 못해요. 되면 그때 더해요 |

## personal-memo 에서 볼 것

[Junjak-Personal/personal-memo](https://github.com/Junjak-Personal/personal-memo) (MIT) 는 폴더와 태그로 메모를 정리하는 앱이에요. 살펴본 날은 2026-11-17, 커밋 `a918fa4` 예요.
웹(Nuxt) 화면이라 코드를 그대로 쓰지는 않고 구조만 참고해요.

| 패턴 | 그쪽에서는 | 우리 화면에서 | 상태 |
|---|---|---|---|
| 폴더 트리 | 왼쪽 목록에서 폴더를 펼치고 접어요. 줄을 길게 누르면 메뉴가 열려요 | 세션 (자료함)과 왼쪽 메뉴: 양식이 폴더, 그 안에 문서 (`TreeRow`) | 넣음 |
| 문서 줄의 저장 상태 | 고치는 중, 저장됨, 기기에 보관, 저장 안 됨 네 가지를 글자로 | 자료함 문서 줄과 편집기 제목 아래 | 넣음 (`SaveStatus`) |
| 즐겨찾기와 최근 문서 빠르게 열기 | 검색 옆 버튼으로 최근 메모와 즐겨찾기를 열어요 | 자료함 맨 위 즐겨찾기 묶음 | 넣음 (즐겨찾기) |
| 목록에서 할 일 체크 | 할 일 메모는 아이콘 자리에 체크 칸이 와요 | 자료함 문서 줄 | 넣음 |
| 목차와 구역 접기 | 편집기 옆에 제목 목차, 구역마다 접기 | 편집기, 녹음 노트 | 넣음 |
| 고친 기록 보고 되돌리기 | 저장할 때마다 기록을 남기고 골라서 되돌려요 | 편집기 더 보기 | 넣음 |
| 문서끼리 잇기 | 메모 안에서 다른 메모를 걸고, 걸린 쪽에서도 보여요 | 문서와 카드 잇기 | 넣음 |
| 태그 모아 보기 | 태그별로 메모를 모아 보는 화면 | 해시태그 화면 | 넣음 |
| 내 양식 저장 | 쓰던 메모를 양식으로 저장해요 | 세션 양식 | 더 보기 메뉴와 초안 시트 칩에 넣음. 저장하는 화면은 아직 |
| 밖에 공개 중 표시 | 공개한 메모와 폴더 줄에 지구본 아이콘 | 피드에 공유한 문서 | 넣음 |
| 찾아 바꾸기 | 메모 안에서 찾아서 바꿔요 | 편집기, 녹음 노트 | 더 보기 메뉴에 줄만 넣음. 화면은 아직 |
| 끌어서 폴더 옮기기 | 줄을 끌어 다른 폴더에 놓아요 (휴대폰에서는 길게 누르기 메뉴로) | 자료함 | 아직 |

## 아직 정하지 않은 것

- 캘린더 기본 보기: 달력만, 반반, 하루만 중 무엇으로 열지 (6번 탭 "캘린더: 달력과 목록"에서 눌러 보고 정해요)
- 날짜 빠른 메뉴의 구성: 일정, 할 일, 메모, 녹음이 맞는지
- 요약 양식을 세션 양식과 완전히 같은 목록으로 쓸지
- 녹음 중 받아쓰는 글을 시트에 보여 줄지 (폰이 더 따뜻해져요)

## 확인하지 못한 것

애니메이션 속도와 진동 느낌, 서버가 정하는 값(횟수 한도 등)은 화면 구성 분석으로 알 수 없었어요. 필요해지면 실제 기기에서 따로 확인해요.
