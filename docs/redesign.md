# 화면 개편

기존 목업은 테두리 상자를 위에서 아래로 나열하는 모양이 많았어요. 한 화면씩 클로바노트와 네이버 캘린더의 화면 구조를 바탕으로 다시 짜요.
구조와 동작 방식만 참고해요. 색, 글꼴, 그림은 우리 디자인 시스템 것을 그대로 써요. 두 앱을 살펴본 내용은 [benchmark/README.md](benchmark/README.md)에 있어요.

## 바꾼 화면

### 홈

| 요소 | 가져온 곳 | 우리 화면에서 |
|---|---|---|
| 상단바: 검색, 알림 | 클로바노트 홈 | 메뉴, 날짜, 검색, 알림 |
| 오늘 브리핑 한 장. 옆으로 밀어 숨김 | 네이버 캘린더 하루 화면 | 다음 일정, 남은 할 일, 확인할 카드를 한 문장으로. 큰 AI 배너를 대신해요 (`BriefingCard`) |
| 일정 줄: 색 막대, 시간 두 줄, 제목과 설명 | 네이버 캘린더 하루 화면 | `AgendaRow`. 막대 색은 연결한 캘린더 색 |
| 오늘 일정 줄에서 바로 녹음 시작 | 클로바노트 홈 | 다가오는 일정에만 「녹음」 버튼 |
| 할 일을 목록에서 바로 체크 | 네이버 캘린더 하루 화면 | `TaskCheckRow` |
| 문서 구역 탭 2개(최근, 공유됨)와 전체 보기 버튼 | 클로바노트 홈 | `CountTabs`, `NoteRow` |
| 문서 줄: 종류 아이콘, 진행 상태, 요약 미리보기, 새 것 표시 | 클로바노트 노트 줄 | `NoteRow` |
| 떠 있는 버튼 하나에서 펼치기 | 둘 다 | `SpeedDial` |

### 오늘 카드

| 요소 | 가져온 곳 | 우리 화면에서 |
|---|---|---|
| 칩 두 줄로 두 기준을 같이 거르기 | 네이버 캘린더 할 일 화면 (기한 줄, 그룹 줄) | 윗줄 상태(전체, 확인할 카드, 확인한 카드), 아랫줄 종류 (`ScrollChips`) |
| 오른쪽 위 정렬 | 네이버 캘린더 할 일 화면 | `SortButton` (최근 만든 순, 시간 빠른 순, 종류별) |
| 목록에서 체크 칸으로 바로 처리 | 네이버 캘린더 할 일 줄 | 왼쪽 동그라미를 누르면 카드 저장 (`CardListRow`) |
| 길게 누르면 동작을 모은 시트 | 클로바노트 받아쓴 글, 노트 목록 | 확인, 고치기, 시간 잡기, 원문 보기, 버리기 (`ActionRow`) |
| 여러 개 한 번에 처리 | 클로바노트 노트 목록의 여러 개 고르기 | 「모두 확인」 |

두 앱과 다르게 한 것: 네이버 캘린더는 지울 때 확인 창을 띄우는데, 우리는 바로 처리하고 되돌리기 막대를 보여 줘요.

### 주간 회고

| 요소 | 가져온 곳 | 우리 화면에서 |
|---|---|---|
| 절반, 전부 달성 때 축하 | 네이버 캘린더 습관 | 맨 위 `CelebrateCard`. 처음 넘긴 순간에는 화면 가득 한 번 |
| 요일별 달성 표시 | 네이버 캘린더 습관 리포트의 주 줄 | `WeekMarks`. 누르면 그날 한 일을 글로 |
| 한 달 진행을 아이콘으로 | 네이버 캘린더 습관 리포트 | `MonthMarks` |
| 공유할 그림 영역 | 네이버 캘린더 습관 리포트 | 아래 「그림으로 공유」 |
| 양식 줄, 접는 구역, 틀릴 수 있다는 안내 | 클로바노트 AI 요약 | `SummaryHeader`, `SummarySection`, `AiNotice` |
| 다음 할 일 | 클로바노트 AI 요약 | 글 목록이 아니라 확인 기다리는 카드 (`NextActionRow`) |

## 같이 지키는 것

- 색만으로 구분하지 않아요. 달성 동그라미는 모양(체크, 차오른 정도)이 다르고 뜻 설명(`MarkLegend`)을 같이 둬요.
- 못 함은 오류가 아니라서 빨강 대신 서브 연한 면을 써요.
- 화면에 채운 버튼은 하나만 둬요.
- AI가 만든 것은 확인해야 저장돼요.

## 같은 모양으로 맞춘 화면

아래 9개는 위 세 화면과 같은 모양 규칙으로 다시 짰어요. 상단바 한 줄, 칩 줄로 거르기, 상자 대신 구분선과 색 띠, 동그라미로 바로 처리, 아래에 주 버튼 하나예요.

| 화면 | 바뀐 점 | 참고한 곳 |
|---|---|---|
| 빠른 입력 | 입력 상자 테두리를 없애고 글을 크게. 도구 한 줄. 찾은 카드는 동그라미로 바로 확인 | 네이버 캘린더 할 일 쓰기(큰 제목 입력), 할 일 체크 |
| AI 채팅 | 채팅 속 카드를 오늘 카드와 같은 줄로. 입력창 위에 바로 묻기 칩 | 클로바노트 요약 양식(자주 쓰는 요청을 골라 쓰기) |
| 세션 (자료함) | 폴더처럼 펼치고 접는 목록. 양식이 폴더이고 그 안에 문서. 즐겨찾기, 공유, 휴지통 묶음 | 클로바노트 폴더 화면, personal-memo 폴더 트리 |
| 편집기 | 상단바 가운데 양식 이름. 제목 아래 상태 칩 한 줄. 키보드 위 서식 막대 한 줄 | 클로바노트 메모 편집(서식 막대는 앱 쪽에) |
| AI 초안 시트 | 글로 적는 대신 양식 칩을 고르고 종류별로 카드를 넣고 빼요. 버튼 아래 남은 횟수 | 클로바노트 요약 만들기(양식 고르기, 남은 횟수 확인) |
| 피드 | 큰 사진 상자 대신 제목과 두 줄 미리보기. 칩으로 거르기 | 클로바노트 공유 받은 노트 목록 |
| 검색 | 탭마다 찾은 개수. 찾은 글자 표시. 녹음 결과에는 시각 | 클로바노트 노트 안 검색(탭에 개수), 네이버 캘린더 검색(한 줄 검색창, 걸러 보기) |
| 시간 잡기 | 날 고르기 칩. 고른 시간이 아래 버튼 글자에 들어가요. 나머지는 설정 줄로 | 네이버 캘린더 할 일 기한 칩(오늘, 내일, 다음주, 직접 설정) |
| 수행 확인 시트 | 동그라미 한 번으로 완료. 줄을 누르면 4가지가 펼쳐져요. 진행 숫자 | 네이버 캘린더 할 일 체크 |

이 화면에서 뺀 것: 편집기 목업의 슬래시 메뉴(컴포넌트 탭에는 남아 있어요), 검색의 그래프 보기(해시태그 연결망은 캘린더 쪽에 있어요).

## 아직 목업이 없는 화면

메모 기록 화면, 메모 휴지통, 편집기 미리보기, 받아쓰기 모델 받기, 로그인, 해시태그 연결망.

## 화면에 쓰는 법을 적지 않아요

「동그라미를 누르면 그날 한 일이 나와요」 같은 쓰는 법 설명은 화면에 넣지 않아요. 눌러 보면 알 수 있게 모양으로 알려 줘요.
남기는 글은 세 가지뿐이에요: 지금 상태(「받아쓰는 중」), 사용자가 알아야 믿을 수 있는 것(「이 기기에만 저장해요」, AI 결과 안내), 눌렀을 때 생긴 결과(되돌리기 막대).
